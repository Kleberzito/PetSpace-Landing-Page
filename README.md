# PetSpace Landing Page

Este projeto foi desenvolvido como um **teste de habilidade** para uma vaga e agora faz parte do meu portfólio.  
A landing page apresenta os serviços da PetSpace, com foco em consultas, vacinas, equipe e planos.

---

## 🚀 Deploy
Acesse a página publicada pelo GitHub Pages:  
👉 [PetSpace Landing Page](https://kleberzito.github.io/PetSpace-Landing-Page/)

---

## 🛠️ Tecnologias utilizadas
- **HTML5** para estrutura
- **CSS3** para estilização
- **JavaScript** para interatividade
- **GitHub Pages** para deploy
